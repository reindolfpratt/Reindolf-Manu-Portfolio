CohbyLearn — Enterprise Learning Platform

Architecting an interactive LMS with course authoring, progress analytics, real-time learner chat, and video calls for 1,000+ attendees.

ROLE

Principal Architect & Developer

TOOLS & TECH

React, Node, Supabase, Video API, Oracle Cloud

TIMEFRAME

May 2025 – Present

MEASURABLE IMPACT

1,000+ Video Attendees | Zero Downtime

THE CHALLENGE

High-Capacity Interactive E-Learning Infrastructure

Organisations delivering technical curriculum needed an intuitive, centralized platform for course authoring, learner progress tracking, interactive quizzes, real-time messaging, and high-capacity live video training sessions without relying on expensive per-user third-party SaaS pricing models.

THE ARCHITECTURE

Full-Stack System Design & Deployment

I designed and built CohbyLearn from the ground up at Cohby Consulting Services:

  • Frontend Application: Built with React for responsive, accessible course rendering, video playback, and real-time student chat interfaces.
  • Database & Authentication: Configured Supabase for user authentication, row-level security (RLS), and database storage of course progress.
  • Live Video Integration: Integrated high-concurrency WebRTC video streaming enabling Zoom-style video sessions for over 1,000 concurrent attendees.
  • Infrastructure Hosting: Administered self-hosted Ubuntu instance on Oracle Cloud, using Tailscale networking, API proxies, and SSL termination.
