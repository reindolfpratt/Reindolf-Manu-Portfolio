Automated AI Content & Media Pipeline

End-to-end automated Reels pipeline integrating n8n workflows, local LLMs, Cloudinary media processing, Supabase DB, and Meta Graph API.

ROLE

Automation & AI Engineer

TOOLS & TECH

n8n, Local LLMs, Cloudinary, Supabase, Meta API

TIMEFRAME

May 2025 – Present

MEASURABLE IMPACT

Daily posting, fully automated

Manual Social Content Operations Overhead

Producing daily short-form video content (Reels), generating brand-aligned captions, formatting media assets, and publishing across multiple commercial Instagram business accounts was taking dozens of hours of repetitive manual effort weekly.

Automated n8n & LLM Workflow Pipeline

I designed a fully automated autonomous pipeline using self-hosted n8n workflows:

  • Media Ingestion & Optimization: Raw media assets are ingested into Cloudinary for automated aspect ratio cropping, text overlay injection, and CDN video encoding.
  • AI Caption Generation: Self-hosted local LLMs parse content metadata to generate engaging, brand-tailored captions and hashtag sets.
  • State Management: Supabase tracks content queuing, publishing statuses, retry logic, and error logs.
  • Automated Publishing: n8n triggers Meta Graph API containers to upload videos and publish directly to Instagram Reels on a scheduled cron cadence.

Production Deployment

Running in production for two commercial brands, posting daily without manual intervention. The pipeline still gets checked in on. Automation that runs unattended for months without anyone watching the error logs is usually automation that's quietly broken.
